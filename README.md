# guten

A small static site generator written in Go. Write posts in Markdown, define layouts with HTML templates, and generate a static site.

## Install

```bash
git clone https://github.com/eFournierRobert/guten.git
cd guten
go install .
```

This will compile the binary and put it in `~/go/bin/`.

## Quick Start

```bash
# Create a project directory
mkdir my-site && cd my-site

# Create required directories
mkdir posts templates assets

# Create required files
echo '<!DOCTYPE html><html><body><h1>My Site</h1></body></html>' > index.html

# Create a post (see Posts section)
# Create a template (see Templates section)

# Build or serve
guten -build   # Build to out/
guten -peek    # Build and serve on http://localhost:5000
```

See [`docs/QUICKSTART.md`](./docs/QUICKSTART.md) for a step-by-step guide.

## Prerequisites

**Before guten can run successfully, you must have:**

1. **`index.html`** in your project root (required)
2. **`assets/`** directory (required) - static files copied to output
3. **`posts/`** directory (required) - Markdown posts with frontmatter
4. **`templates/`** directory (required) - HTML templates for rendering

> **See [`docs/STRUCTURE.md`](./docs/STRUCTURE.md) for a detailed structure guide.**

## Project Structure

```
my-site/
├── index.html      # Required: copied to out/index.html
├── assets/         # Required: copied to out/assets/
│   └── ...         # CSS, JS, images
├── posts/          # Required: Markdown posts
│   └── *.md
├── templates/      # Required: HTML templates
│   └── *.html
└── out/            # Generated by guten (don't edit)
    ├── index.html
    ├── assets/
    └── posts/
```

## Build & Serve

### Build

```bash
guten -build
```

Generates static files in `out/` directory.

### Peek (Serve)

```bash
guten -peek
```

Builds the site and starts an HTTP server on `http://localhost:5000`.

## Posts

Posts are Markdown files with YAML frontmatter:

```markdown
---
date: 2024-01-15
title: Hello World
excerpt: My first post
template: post
tags:
  - blog
---

# Content in Markdown
```

**Required frontmatter fields:**

| Field | Description |
|-------|-------------|
| `date` | Publication date (YYYY-MM-DD) |
| `title` | Post title |
| `excerpt` | Summary for previews |
| `template` | Template name (without .html) |
| `tags` | Array of tag names |

## Templates

Templates are HTML files with special tags that get replaced:

```html
<!DOCTYPE html>
<html>
<body>
    <h1>{{ title }}</h1>
    <p class="date">{{ date }}</p>
    <div class="content">{{ content }}</div>
</body>
</html>
```

**See [`docs/TEMPLATES.md`](./docs/TEMPLATES.md) for the complete template reference.**

## Template Variables

| Variable | Description |
|----------|-------------|
| `{{ title }}` | Post title |
| `{{ date }}` | Post date (YYYY-MM-DD) |
| `{{ excerpt }}` | Post excerpt |
| `{{ content }}` | Rendered Markdown content |

## Output Structure

After build, `out/` contains:

```
out/
├── index.html      # From your root index.html
├── assets/         # Copied from assets/
└── posts/          # Generated post pages
    └── *.html
```

## Reserved Tags

⚠️ Tags named `title`, `content`, `date`, or `excerpt` are **reserved** and will cause errors.

Use alternative names like `blog`, `news`, `tutorial`.
