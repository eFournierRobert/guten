# Quick Start Guide

Get up and running with guten in 5 minutes.

## Step 1: Install guten

```bash
git clone https://github.com/eFournierRobert/guten.git
cd guten
go install .
```

## Step 2: Create a Project

```bash
guten -init my-website
cd my-website
```

This creates the required `posts/`, `templates/` and `assets/` directories, the optional `includes/` directory, and a basic `index.html`. The `posts/` and `templates/` directories start empty, so you still need to create your first post and template (next steps). The post can be created with `guten -new-post` or written by hand.

## Step 3: Create a Post

The easiest way is to ask guten for a starter post - it fills in today's date, a placeholder title, excerpt and the `post` template, plus a random placeholder line where your content belongs:

```bash
guten -new-post posts/hello-world.md
```

It creates the post at the path you give (anywhere inside `posts/`, including subdirectories). If the file already exists, guten asks before overwriting it. Then open the file and replace the placeholders with your own content:

```markdown
---
date: 2024-01-15
title: Hello World
excerpt: My first post with guten
template: post
tags:
  - blog
---

Welcome to my website! This is my **first post**.

I'm using guten to build this static site.
```

## Step 4: Create a Template

Create `templates/post.html`:

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>{{ title }}</title>
</head>
<body>
    <h1>{{ title }}</h1>
    <p class="date">{{ date }}</p>
    <hr>
    <p class="excerpt">{{ excerpt }}</p>
    <div class="content">
        {{ content }}
    </div>
</body>
</html>
```

## Step 5: Build & Preview

```bash
# Build the site
guten -build

# Or serve locally with live preview
guten -peek
```

Your site is now available at `http://localhost:5000`.

## Complete Example Structure

After following this guide, your project should look like:

```
my-website/
├── index.html              # Required: copied to out/
├── assets/                 # Required: copied to out/
│   └── (your static files)
├── includes/               # Optional: reusable HTML snippets
│   └── (e.g. footer.html)
├── posts/
│   └── hello-world.md      # Your first post
├── templates/
│   └── post.html           # Template for posts
└── out/                    # Generated by guten
    ├── index.html
    ├── assets/
    └── posts/
        └── hello-world.html
```
