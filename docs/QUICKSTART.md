# Quick Start Guide

Get up and running with guten in 5 minutes.

## Step 1: Install guten

```bash
git clone https://codeberg.org/efournierrobert/guten.git
cd guten
go install .
```

## Step 2: Create a Project

```bash
guten -init my-website
cd my-website
```

This creates the required `posts/`, `templates/` and `assets/` directories along with a basic `index.html`. The `posts/` and `templates/` directories start empty, so you still need to create your first post and template (next steps).

## Step 3: Create a Post

Create `posts/hello-world.md`:

```markdown
---
date: 2024-01-15
title: Hello World
excerpt: My first post with guten
template: post
tags:
  - blog
---

Welcome to my website! This is my **first post**.

I'm using guten to build this static site.
```

## Step 4: Create a Template

Create `templates/post.html`:

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>{{ title }}</title>
</head>
<body>
    <h1>{{ title }}</h1>
    <p class="date">{{ date }}</p>
    <hr>
    <p class="excerpt">{{ excerpt }}</p>
    <div class="content">
        {{ content }}
    </div>
</body>
</html>
```

## Step 5: Build & Preview

```bash
# Build the site
guten -build

# Or serve locally with live preview
guten -peek
```

Your site is now available at `http://localhost:5000`.

## Complete Example Structure

After following this guide, your project should look like:

```
my-website/
├── index.html              # Required: copied to out/
├── assets/                 # Required: copied to out/
│   └── (your static files)
├── posts/
│   └── hello-world.md      # Your first post
├── templates/
│   └── post.html           # Template for posts
└── out/                    # Generated by guten
    ├── index.html
    ├── assets/
    └── posts/
        └── hello-world.html
```
