# A Second Post

This is my second post! I'm getting the hang of guten.

## Features I like

1. **Simple setup** - Just Markdown and templates
2. **No dependencies** - Pure Go, no Node.js or Ruby needed
3. **Static output** - Perfect for hosting anywhere

## Try it yourself

1. Clone this repo
2. Create your own posts in `posts/`
3. Customize templates in `templates/`
4. Run `guten -build`

Happy blogging!
